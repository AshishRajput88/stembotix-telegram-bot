# 🤖 STEMbotix Telegram AI Auto-Assign Review Bot

100% Secure, Private aur Easy! Is Telegram bot se aap direct apne mobile phone se **PDF, Word (.docx), Excel ya Text file** bhej kar automatically reviews assign kar sakte hain. **Website ya laptop kholne ki zaroorat nahi hai.**

---

## ⚡ 1-Minute Setup Guide (Kaise Start Karein)

### Step 1: Telegram Par Apna Bot Banao (30 Seconds)
1. Apne phone me Telegram app kholein aur search karein: **`@BotFather`**
2. `@BotFather` ko message bhejein: **`/newbot`**
3. Bot ka **Name** daalein (e.g. `STEMbotix Review Bot`).
4. Bot ka **Username** daalein (e.g. `stembotix_review_bot` — end me `bot` hona chahiye).
5. `@BotFather` aapko ek **HTTP API Token** dega (jaise `7823498234:AAH...`).

### Step 2: Token Ko .env File Me Paste Karein
- `telegram-ai-bot/.env` file Notepad me kholein aur token paste kar dein:
  ```env
  TELEGRAM_BOT_TOKEN=7823498234:AAHxxxxxxxxxxxxxxxxxxxxxx
  ```

### Step 3: Bot Start Karein
- **`START-BOT.bat`** par double click karein!
- Command prompt me likha aayega: `🚀 STEMbotix Telegram AI Bot is RUNNING & LISTENING!`

---

## 📲 Kaise Use Karein:
1. Telegram me apne banaye huye bot ko search karke kholein.
2. `/start` dabayein.
3. Ab koi bhi **PDF**, **Word file**, **Excel**, ya **Text message** bot ko bhej dein.
4. Bot turant document padhega, har product ko alag divide karega, Firebase database me assign karega aur confirmation report bhej dega!
